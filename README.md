# Stranger Things

Stranger Things is a fan-made tribute website inspired by the iconic Netflix series, built with a focus on delivering an immersive, atmospheric, and visually engaging experience.

The project was developed using HTML, Tailwind CSS, and GSAP, combining utility-first styling with powerful scroll-based animations. The page captures the eerie and nostalgic aesthetic of the show through carefully crafted transitions, animated text effects, and a dark, cinematic layout.

## Features

- Scroll-triggered animations with GSAP and ScrollTrigger
- Responsive layout with Tailwind CSS utility classes
- Custom typography with Stranger Things-inspired fonts
- Dark, atmospheric UI reflecting the show's visual identity

<br>

## Project Structure

```
Stranger-Things/
├── assets/         # Images and media files
├── fonts/          # Custom typography
├── js/             # JavaScript and GSAP animation scripts
├── src/            # Source styles (Tailwind input)
├── index.html      # Main HTML file
└── package.json    # Project dependencies
```

## Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed.

### Installation

```bash
# Clone the repository
git clone https://github.com/anacatsousa/Stranger-Things.git

# Navigate into the project folder
cd Stranger-Things

# Install dependencies
npm install
```

### Run locally

```bash
npm run dev
```
